# Especificações da Landing Page (Tratto)

Toda funcionalidade, tela ou componente da Landing Page começa aqui (ADR 0006).

## Fluxo Rigoroso: SDD + TDD

1. **Especificar:** criar `NNNN-nome.md` a partir de `0000-template.md`.
2. **Revisar e aprovar:** o dev lê, ajusta e marca como `aprovada`. Sem aprovação, não há código.
3. **Testes primeiro (TDD):** escrever os testes a partir dos critérios de aceitação. Rodar e confirmar que **falham**.
4. **Implementar** o mínimo para os testes passarem.
5. **Refatorar** com os testes passando.
6. **Fechar:** marcar a spec como `implementada`.
